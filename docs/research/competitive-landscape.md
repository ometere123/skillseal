# Competitive landscape

Public BOT Challenge #2 project details were not discoverable from an official index during this build. This avoids unverified competitor claims.

| Category | Overlap | SkillSeal distinction |
|---|---|---|
| Agent-wallet safety | Protects a wallet or transaction | SkillSeal evaluates the agent-tool boundary before authority is granted. |
| Transaction simulation | Assesses an individual transaction | SkillSeal binds a versioned tool manifest to a mandate and rejects stale trust. |
| MCP marketplaces | Discovery and distribution | SkillSeal supplies provenance, capability deltas, policy and payment gating. |
| Reputation systems | Historic provider signals | A bond/seal is not treated as a safety guarantee; exact current state is required. |

SkillSeal’s category is **agent-to-tool trust infrastructure**: a provider cannot silently inherit an agent’s trust after changing declared authority.
